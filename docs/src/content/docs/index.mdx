title: docevals
description: Deterministic and LLM-as-judge evals for documentation pages, driven by frontmatter.
---

docevals turns every quality check on a documentation page into an **eval**: a named, testable
assertion with a **grader** that decides pass or fail. Graders run in preference order — code first,
an LLM judge second, a human last.

This site is being built out. Until it is, the [README](https://github.com/hawkeyexl/docevals#readme)
is the complete reference.
