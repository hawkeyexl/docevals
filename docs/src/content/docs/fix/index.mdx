You did not configure this check and you do not need to learn the tool. This page will get you from a
red check to a green one.

This section is planned and not yet written. It will cover:

- Telling the failure types apart — a finding with a line number, an LLM verdict with a rationale, an
  eval awaiting human review, a stale generated script, and an operational error that is not your fault
- Reading the assertion and its failing example alongside the rationale to find the offending sentence
- Which failures are not yours to fix, and who to hand them to
- Reproducing the check locally without a provider key

Until then, ask whoever configured the check, or see the
[README](https://github.com/hawkeyexl/docevals#readme).
