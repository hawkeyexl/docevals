When the report needs to feed something other than a human — a dashboard, a PR bot, a quality
scorecard — use `--format json` or the library directly.

## `--format json`

One object per run. Full field reference in
[Output and exit codes](/docevals/reference/output-and-exit-codes/).

```bash
npx docevals run --format json > docevals.json
```

```json
{
  "pages": 1,
  "evalResults": [ { "evalName": "fresh-enough", "outcome": "fail", "findings": [ … ] } ],
  "suites": [ { "suite": "reference", "passRate": 0.666…, "targetPassRate": 1, "meetsTarget": false } ],
  "cost": { "totalUsd": 0, "totalTokens": 0, "cachedEvals": 0, "judgedEvals": 0 },
  "generated": [],
  "exitCode": 1
}
```

Primary output goes to stdout, so redirect it. Diagnostics go to stderr.

## Useful queries

Findings, flattened for a table:

```bash
npx docevals run --format json \
  | jq -r '.evalResults[] | select(.findings) | .findings[]
           | [.file, .line // "-", .severity, .evalName, .message] | @tsv'
```

Suites missing their target:

```bash
npx docevals run --format json \
  | jq -r '.suites[] | select(.meetsTarget | not)
           | "\(.suite): \(.passRate * 100 | floor)% vs \(.targetPassRate * 100)%"'
```

Cache effectiveness — the number that tells you whether your CI cache is working:

```bash
npx docevals run --format json | jq '.cost | {cachedEvals, judgedEvals, totalUsd}'
```

Evals awaiting a person:

```bash
npx docevals run --format json \
  | jq -r '.evalResults[] | select(.outcome == "needs-review") | "\(.file) \(.evalName)"'
```

## Track quality over time

`suites[].passRate` is the metric worth storing. Push it wherever your team already looks:

```bash
npx docevals run --format json \
  | jq -c '{ts: now, suites: [.suites[] | {suite, passRate, meetsTarget}]}' \
  >> metrics/docs-quality.jsonl
```

Capability suites are the interesting series — a regression suite should sit flat at 1.0, while a
capability suite's rate is the actual measure of a quality goal spreading. See
[Regression vs capability](/docevals/evals/regression-vs-capability/).

## The TypeScript API

The package exports the frontmatter schema for consumers that validate pages themselves:

```js
import { frontmatterSchema, frontmatterSchemaPath } from "docevals";
```

`frontmatterSchema` is the parsed schema object; `frontmatterSchemaPath` is its resolved path on
disk, for handing to another validator.

## Beware of parsing the human format

`--format human` is for people, and its layout is not a contract. Colour depends on TTY detection,
and the wording can change in any release. Parse `json`; it is the shape that is versioned.

## Exit codes still apply

The JSON carries `exitCode`, and the process exits with it. Scripts should branch on the process exit
code rather than re-deriving pass/fail from the report — and keep `1` and `2` distinct. See
[Exit codes and annotations](/docevals/ci/exit-codes-and-annotations/).
